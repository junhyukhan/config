# Cross-harness instructions — public summary

The original personal incident and decision record has been retained verbatim in
a private archive. This summary is not a claim about any currently installed
harness or its instruction-loading behavior.

A self-referential import can look configured while loading no useful rules.
Check the actual resolved file and the harness's documented loading mechanism;
do not infer support for one harness's import syntax in another. A symlink can
avoid duplicate copies, but successful path resolution alone does not prove that
a harness reads the path. Keep runtime state outside the public configuration
repository, and verify behavior separately from file layout.
