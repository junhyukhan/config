# Publishing permissions — public summary

The original personal decision record, including its amendments and verbatim
statements, has been retained in a private archive. This page does not establish
a new standing grant or reproduce that history as current operational policy.

A narrow docs-only exception must not silently expand into permission to change
runtime behavior, publish, merge, delete branches or act on another repository.
Mechanical permission gates and written task authorization are separate checks.
Current task instructions and the repository's `AGENTS.md` govern the work.

When a grant is unclear, resolve that uncertainty before taking the outward action.
